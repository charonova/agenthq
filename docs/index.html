Your agents,

AgentHQ turns every live Claude Code and Codex session into a pixel-art office. The main agent is the manager, every teammate gets a desk, and the helpers they start sit beside them. Watch them type, test, talk to each other and take coffee breaks, live.

▶ Run it ★ Star on GitHub
Free and open source · macOS, Linux and Windows · runs on your machine only
The office

One session, one office. One agent, one desk.

A session with an agent team can have dozens of agents. AgentHQ shows who they are, what each is doing right now, and who is waiting for you.

👔

The manager

The session's main agent works from a glass office, and watches the team while they work.

🧑‍💻

The staff

Every teammate gets a desk with its name, in its team colour. They walk over to each other's desks to talk.

🧑‍🎓

The interns

The helpers a teammate starts sit at the table beside it, and go home when they're done.

Run it

One command.

You need Node.js 20 or later.

# open the office at http://localhost:4747 npx @charonova/agenthq # or install it npm install -g @charonova/agenthq agenthq
Where it looks What it learns
~/.claude/projects/*/*.jsonl Live sessions, each one an office, and its manager
<session>/subagents/*.jsonl and .meta.json Teammates (name, colour, model) and the helpers they start
The last lines of each transcript What each agent is doing now, and for how long

Private by design. AgentHQ only reads what Claude Code writes on your computer, never changes it, and serves the office on 127.0.0.1 only. Nothing leaves your machine.
