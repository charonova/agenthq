# AGENTS.md

AgentHQ turns live Claude Code sessions into a 2D pixel-art office: one office per session, the session's agent as manager, teammates as staff, their helpers as interns. A Node CLI reads `~/.claude` and serves a local page; the page draws the building with PixiJS.

## Layout

| Path                                | Responsibility                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `packages/core/src/tail.ts`         | Reading the end of a transcript (never the whole file) and what its last lines say: step, tool, title, context                                                                                                                                                                                                                                                                                                                                   |
| `packages/core/src/state.ts`        | Turning that into what the office shows: working, waiting, done, idle (coffee, couch), gone                                                                                                                                                                                                                                                                                                                                                      |
| `packages/core/src/office.ts`       | Finding live sessions (from a list of recently used ones, redone every 30 s) and building offices: manager, staff, interns                                                                                                                                                                                                                                                                                                                       |
| `packages/cli/src/server.ts`        | The local server: the page, `/api/offices`, `/events` (Server-Sent Events: `offices` only on change, rescanning every 2 s and on file changes; `asks`; `draft`), `/api/conversation`, `/api/replay`, `/api/jump`. 127.0.0.1 only                                                                                                                                                                                                                 |
| `packages/core/src/conversation.ts` | An agent's conversation, a page (byte range cut at line breaks) at a time: newest, `before` an offset, or `since` one; Claude Code and Codex lines as one `Message` type                                                                                                                                                                                                                                                                         |
| `packages/core/src/processes.ts`    | Running sessions from `~/.claude/sessions/<pid>.json` (pid ↔ session id), live processes only                                                                                                                                                                                                                                                                                                                                                    |
| `packages/core/src/codex.ts`        | Codex threads as offices: rollouts under `~/.codex/sessions` (head: `session_meta` with `parent_thread_id` for sub-agents; tail: `task_started`/`task_complete`, `item_completed` actions, `request_user_input_async`), names from `session_index.jsonl`                                                                                                                                                                                         |
| `packages/core/src/sources.ts`      | Where offices come from: one `AgentSource` per agent CLI (Claude Code, Codex): its folder, its offices, its conversation and replay parsing, its resume command; `discoverAll` merges them. A new source adds a `kind` to `Office['kind']` and an entry here                                                                                                                                                                                     |
| `packages/core/src/tasks.ts`        | A session's team tasks: its list folder (from the teams' configs, or `session-<id8>`), task files read defensively and cached until the folder changes                                                                                                                                                                                                                                                                                           |
| `packages/core/src/usage.ts`        | Tokens per transcript: its last part at first, then what's appended; sums per office                                                                                                                                                                                                                                                                                                                                                             |
| `packages/core/src/replay.ts`       | A session's last hours as each agent's timed steps, read backwards only as far as needed                                                                                                                                                                                                                                                                                                                                                         |
| `packages/cli/src/hook.ts`          | Answering from AgentHQ: the `PermissionRequest` hook script (plain Node, written to `~/.agenthq`), adding/removing it in `~/.claude/settings.json` with a backup                                                                                                                                                                                                                                                                                 |
| `packages/cli/src/asks.ts`          | Prompts waiting on you: held open for the hook until you answer, the terminal answers (the transcript moves on), the hook gives up, or they expire                                                                                                                                                                                                                                                                                               |
| `packages/cli/src/sessions.ts`      | Sessions AgentHQ runs: the Agent SDK (bundled, loaded on first use) over the user's own `claude`; streaming input for messages, `canUseTool` into `Asks`, resume by id; the reply being written (`includePartialMessages` → `nextDraft`) goes to the page as `draft` events until its transcript line lands                                                                                                                                      |
| `packages/cli/src/jump.ts`          | Going to a session: the process table → the app above the session's process (Codex: the `codex` process in the thread's folder) → a plan (Terminal/iTerm2 tab by tty, editor window by folder, the app, or copying `claude --resume`), then carrying it out                                                                                                                                                                                      |
| `packages/cli/src/typing.ts`        | Typing into a session open in Terminal/iTerm2 (macOS, opt-in, `~/.agenthq/config.json`): its tab by tty, the message as an AppleScript argument after `--` (never in the script), one line; else the page copies it                                                                                                                                                                                                                              |
| `packages/cli/src/cli.ts`           | `agenthq` (opens the office), `--list` / `--json`, `--port`, `--no-open`                                                                                                                                                                                                                                                                                                                                                                         |
| `apps/web/src/scene/layout.ts`      | The floor plan in tiles, and which tiles furniture blocks                                                                                                                                                                                                                                                                                                                                                                                        |
| `apps/web/src/scene/path.ts`        | A* on the floor plan, so people walk around furniture                                                                                                                                                                                                                                                                                                                                                                                            |
| `apps/web/src/scene/plan.ts`        | Who goes where for what they're doing, and what their bubble says (pure: tested)                                                                                                                                                                                                                                                                                                                                                                 |
| `apps/web/src/scene/motion.ts`      | Sitting down and getting up (`stepSeat`: a crouch between, up before walking), and when the door stands open (pure: tested)                                                                                                                                                                                                                                                                                                                      |
| `apps/web/src/scene/art/`           | Pixel art drawn in code: `people` (a look per name: skin, hair, style, figure; a chosen `LookChoice` overrides parts), `furniture`, `paint`                                                                                                                                                                                                                                                                                                      |
| `apps/web/src/scene/textures.ts`    | Art drawn once into cached textures (a person's look × pose × frame)                                                                                                                                                                                                                                                                                                                                                                             |
| `apps/web/src/scene/OfficeScene.ts` | One office in PixiJS: layers, depth sorting, walking, bubbles, name tags, night                                                                                                                                                                                                                                                                                                                                                                  |
| `apps/web/src/scene/World.ts`       | The PixiJS app and camera (pixi-viewport): offices on one map, zooming into one, clicks                                                                                                                                                                                                                                                                                                                                                          |
| `apps/web/src/state/search.ts`      | Finding agents across offices by name, project, task or a tool's target, with filters (pure: tested); `ui/Find.tsx` is its box in the header                                                                                                                                                                                                                                                                                                     |
| `apps/web/src/state/view.ts`        | What the settings decide, as plain functions (tested): day/night by theme, reduced motion, which offices show, whose look a choice is (`lookKeyOf`)                                                                                                                                                                                                                                                                                              |
| `apps/web/src/state/`               | Zustand store (`useSettings`: this viewer's settings, persisted in the browser; `offices` are the shown ones, `allOffices` all); the event stream (`?once` loads once); the `#/office/<id>` route; `useKeyboard` (Esc steps back one thing at a time: dialog, settings, conversation, person, office; focus returns where you were), `useMotion` (reduced motion: the settings or `prefers-reduced-motion`, marked as `data-motion` on the page) |
| `apps/web/src/ui/`                  | React: header (🔔 opens the alerts settings, ⚙️ all of them), the canvas host, the side panel (🎨 `LookEditor`), the conversation (`Chat`, with a Markdown renderer that makes elements, never HTML), `Settings`                                                                                                                                                                                                                                 |
| `e2e/`                              | Playwright on a made-up `~/.claude` (`fixture-home.mjs`), served by `serve.mjs`                                                                                                                                                                                                                                                                                                                                                                  |

## Commands

`pnpm dev` (server + Vite, hot reload) · `pnpm check` (lint, format, types, tests) · `pnpm build` · `pnpm e2e` (after a build) · `pnpm start` · `pnpm bench` (main-thread time per second with 180 made-up agents, `--software` without the GPU; run it before and after a change to the scene).

## Rules

- **Read only.** Never write to `~/.claude`, never run Claude Code, never send anything off the machine. Sessions the user starts or resumes from the page are the exception to "never run": the Agent SDK runs their own `claude` (`findClaude`: a program, or behind npm's `claude.cmd` on Windows the `cli.js` it names, run with node; never the SDK's ~300 MB platform binaries, which `pnpm-workspace.yaml` leaves out), with `AGENTHQ_MANAGED=1` so the hook steps aside, and they end when AgentHQ closes. Only a session known to have ended (`office.ended`) can be resumed here: one open in a terminal would get two writers. Tests run a stand-in (`AGENTHQ_TEST_AGENT=e2e/fake-agent.mjs`), never real Claude Code. The other exception: when you turn on answering from AgentHQ (and only then), `setAnswering` adds or removes its own hook in `~/.claude/settings.json`, saving a copy first and leaving every other key and hook as it was.
- **The hook endpoint (`POST /api/hook`) needs the secret** written to `~/.agenthq/server.json` (0600) at each start; `/api/answer` and `/api/answering` are guarded like the jump. The page can only allow, deny, pick one of Claude Code's own suggestions, or answer the questions asked: it can never change what a tool runs. Answers are logged (names and choices only) in `~/.agenthq/answers.log`.
- **Whatever goes wrong, the terminal decides**: the hook prints nothing on any error, without AgentHQ, or without an answer.
- **Replay** (`replay.ts`, `GET /api/replay`, guarded like the conversation): each agent's transcript is read backwards a 256 KB page at a time until the window's start (1–12 hours, at most 8 MB per agent), as steps (prompt, tool, reply, done). The page rebuilds the office at a moment (`state/replay.ts`, pure) and the same scene draws it.
- **Tokens** (`usage.ts`): a Claude Code transcript is counted from its last 1 MB when first seen (`partial`), then only appended bytes (4 MB per scan at most); a reply counts once by `message.id`. Codex: the last `token_count`'s `total_token_usage`.
- **Never read a whole transcript.** They reach gigabytes: read the last ~96 KB (and the first ~32 KB for the title). Rescans reuse tails until a file changes. Conversations are read a 192 KB page at a time; one entry larger than a page is read whole up to 16 MB, else skipped.
- **`GET /api/conversation` is guarded like the jump**: the `X-AgentHQ: 1` header, a localhost `Host`, and only an agent in the office now: the page names a session and an agent, never a file.
- **The format isn't documented.** Parse defensively: unknown line types are skipped, missing fields are null. Every field the reader relies on gets a test with a line shaped like the real one (compact JSON, no space after `:`).
- **Team tasks come from `~/.claude/tasks/<list>/<id>.json`** (`tasks.ts`): the list is the team named in `~/.claude/teams/<name>/config.json` whose `leadSessionId` is the session (only `name` and `leadSessionId` are read there), else `session-<first 8 of the id>`. Only `id`, `subject`, `status`, `owner`, `blockedBy` are kept. Who talks to whom comes from `SendMessage` calls in the tails (`Tail.sent` → `Office.talks`), with the lead's names (`team-lead`…) shown as Manager.
- **Staff and interns come from `.meta.json`**: `spawnDepth: 0` / `taskKind: in_process_teammate` is a teammate (`name`, `color`, `model`, `permissionMode`); deeper ones are helpers with `parentAgentId` and `finished`. Helpers work in the permission mode of whoever started them.
- **Tests and screenshots never use real transcripts or names.** Use made-up data shaped like the real thing (`e2e/fixture-home.mjs`).
- **`POST /api/jump` is guarded**: POST only, the `X-AgentHQ: 1` header (other sites can't send it without a CORS preflight, never answered), a localhost `Host` (no DNS rebinding), and only sessions in the office. It runs programs directly (`osascript`, `open`, `ps`, `lsof`; on Windows `powershell.exe` with one fixed query, `windowsProcessQuery`; an editor's own program with the folder as its only argument), never a shell; a tty goes into AppleScript only as `ttys123`. Linux (`hostOfLinux`, by process name) and Windows (`hostOfWindows`): an editor opens the session's folder; a terminal can't be steered to a tab, so the command is copied, naming it.
- **Never read `~/.claude/sessions/*.key`**: they're secrets. Only `<pid>.json`.
- **Claude Code's own `status` beats guessing, for the lead only** (`applyStatus`; words from Claude Code 2.1's own code, not guessed): `busy` → working (a pending tool is running); `waiting` → needs you, with `waitingFor` (only its own words: `permission prompt`, `input needed`, `dialog open`, `goal proposal`, `sandbox request`); `idle` with a pending tool → waiting for you (older versions); `idle` otherwise → its turn is over; `shell` → its turn is over but a background command still runs (rest `background`: by the server rack). Other words leave the guess from the transcript's quiet time alone. A session with no process (where `~/.claude/sessions` exists) has ended: nobody in it works or waits. A running session stays in the building however long it's quiet.
- **Codex: never read `~/.codex/auth.json`** (its login). Codex's newer tool calls are scripts (`exec` runs JavaScript), so activity comes from finished `item_completed` actions. Codex keeps no pid ↔ thread file: going to a Codex session (macOS) finds a running `codex` whose folder (`lsof -a -p <pid> -d cwd -Fn`) is the thread's, preferring one in a terminal tab, then one in an app, and uses the same plan as Claude Code; else it copies `codex resume <id>`. Two threads in one folder can't be told apart.
- **Pictures and tests point both `AGENTHQ_CLAUDE_HOME` and `CODEX_HOME` at made-up folders**, so no real session ever shows up.
- **Tests never open real windows**: the e2e server runs with `AGENTHQ_JUMP=copy`, which also makes typing into terminals only copy the message.
- **Typing into terminals is off until the user turns it on** (`POST /api/typing`, guarded like the jump; AgentHQ's own `config.json`, never Claude Code's settings). `POST /api/type` types only into the tab of a Claude Code session running in a terminal, found by a tty that matches `ttys\d+`; the text goes to `osascript` as an argument, never into the script, with line breaks made spaces and control characters dropped.
- **The server listens on 127.0.0.1 only.** Text from transcripts reaches the page as text (React children, Pixi `Text`), never as HTML.
- **Idle costs little.** The scene runs at 30 fps at most and stops in a hidden tab; art is drawn once into textures, and each frame only swaps them. A frame is drawn only when something changed (`OfficeScene.tick` says so; the camera's `dirty`), offices outside the view aren't drawn (`renderable`, so they still count for bounds), and zoomed out people animate half as often.
- **Pure logic stays out of PixiJS.** Layout, paths and plans are plain functions with tests; the scene only draws what they decide.
- **Pixi classes extend `Container`**: don't reuse its member names (`label`, `height`, `width`…).
- pnpm blocks dependencies' install scripts; only `esbuild` is allowed (`pnpm-workspace.yaml`).
